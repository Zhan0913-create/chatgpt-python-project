# ChatGPT + Python Project

Бұл мини жобада Python және JavaScript арқылы ChatGPT API-мен жұмыс жасалады. HTML интерфейсі бар веб-қосымшаны көруге болады.

## Негізгі мүмкіндіктер
- Python server
- HTML + JavaScript интерфейс
- ChatGPT API-мен сұрақ-жауап
- GitHub-ге дайын құрылым

## Қажеттіліктер
- Python 3.9+
- OpenAI API key

## Орнату

1. Репозиторийді клондарыңыз:
```bash
git clone https://github.com/Zhan0913-create/chatgpt-python-project
cd chatgpt-python-project
```

2. Зависимостілерді орнатыңыз:
```bash
pip install -r requirements.txt
```

3. API key қосыңыз:
```bash
export OPENAI_API_KEY="your_api_key_here"
```

Windows үшін:
```bash
set OPENAI_API_KEY=your_api_key_here
```

4. Серверді іске қосыңыз:
```bash
python main.py
```

5. Браузерде ашыңыз:
```text
http://127.0.0.1:5000
```

## Файлдар
- `main.py` — Flask сервері
- `templates/index.html` — HTML интерфейс
- `static/script.js` — JavaScript логикасы
- `requirements.txt` — Python пакеттары
